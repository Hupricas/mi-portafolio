Después, publica con GitHub Desktop

  1. Abre GitHub Desktop y selecciona el repositorio donde está esta carpeta mi-portafolio.
  2. Comprueba los cambios, escribe una descripción (por ejemplo, «Actualización del portafolio») y pulsa Commit to main.
  3. Pulsa Push origin. GitHub Pages actualizará tu página tras desplegar la nueva versión.

Importante: para publicar sin copiar archivos, trabaja directamente dentro de la carpeta de tu repositorio GitHub. No subas la carpeta copias-seguridad (se excluye con .gitignore).
